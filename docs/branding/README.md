# PREDVAL identity

The coverage-grid mark represents a declared roster: one open cell, one highlighted cell, and a pair of brackets. It is a project identity, not a clinical certification mark.

## Assets

- `predval-lockup-light.svg` and `predval-lockup-dark.svg`: horizontal logo for light and dark backgrounds.
- `predval-icon-light.svg` and `predval-icon-dark.svg`: standalone square icon.

All assets are transparent SVGs. Wordmarks use outlined paths and require no installed font. The root README selects the dark asset using `prefers-color-scheme` and supplies a light fallback with descriptive alt text.

## Usage

Use the light assets on white and the dark assets on a dark background such as `#0C1626`. Keep the horizontal logo at least 240 px wide. The icon has been checked at 32, 128, and 512 px. Preserve its aspect ratio and leave at least one grid-cell width of clear space around unrelated content.

Palette: navy `#112D49`, violet `#6952C7`; dark-background foreground `#EDF3FA`, violet `#AD9AF4`.

The wordmark is derived from DejaVu Sans Bold, with custom tracking and conversion to paths. See [FONT-LICENSE.txt](FONT-LICENSE.txt) for the font copyright and license notice. No font binaries are included.
