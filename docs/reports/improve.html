Rows are ordered with demonstrated repairs first (by rung, then by interval strength), then the remaining members by their best gain estimate -- the largest point estimate is not the strongest evidence. Each cell is the paired cross-fit Brier gain -- rung0 Brier minus that rung's held-out Brier, positive when recalibration helped -- with its paired cluster-bootstrap interval (a gain whose interval excludes 0 is a real out-of-fold improvement). The apparent, in-sample gains run larger; only the cross-fitted gains, which hold whole patients out, are shown. rung1's apparent intercept is ~0 and rung2's apparent slope is ~1 by construction (that is what each fit targets), so those are not reported as findings. Recalibration cannot improve discrimination; the cross-fitted Brier is the expected loss after local recalibration, not a validated result.

Limitations

The optimism correction covers the recalibration step only. predval evaluates the predictions it is handed and has no view of how they were produced. If model selection or tuning used patients inside this cohort, rung0 is itself optimistically biased and this harness cannot see it; only a cohort the model was never tuned on could expose that. The paired cross-fit gain interval (section 3) conditions on the fitted correction -- it resamples the patient-level loss difference but does not refit the correction inside each bootstrap replicate, so it does not carry the correction's own fitting variance; that refit-in-replicate interval remains backlog (spec section 4.5).
