3. Calibration diagnosis (subordinate to section 2)

This section diagnoses rung0; it does not rank models. Rows are ordered by the best per-member gain. Each cell is the paired cross-fit Brier gain -- rung0 Brier minus that rung's held-out Brier, positive when recalibration helped -- with its paired cluster-bootstrap interval (a gain whose interval excludes 0 is a real out-of-fold improvement). The apparent, in-sample gains run larger; only the cross-fitted gains, which hold whole regions out, are shown. rung1's apparent intercept is ~0 and rung2's apparent slope is ~1 by construction (that is what each fit targets), so those are not reported as findings. Recalibration cannot improve discrimination; the cross-fitted Brier is the expected loss after local recalibration, not a validated result.

At small G the flexible rung is high-variance under cross-fitting: absence of a rung3 gain is evidence of linear miscalibration only insofar as rung3 had power to detect shape distortion.

Limitations

The paired cross-fit gain interval (section 3) conditions on the fitted correction -- it resamples the region-level loss difference but does not refit the correction inside each bootstrap replicate, so it does not carry the correction's own fitting variance; that refit-in-replicate interval remains backlog (spec section 4.5).
