# GUSTO-I golden baseline

Frozen regression baseline for the GUSTO-I second worked example. Generated by:

```bash
uv run --group examples python examples/gusto/run_evaluation.py
```

(default config: `B=2000`, `seed=1337`, from `examples/gusto/cohort.yaml`; single model
`gusto_west_refit_logistic`, non-West cohort n=38,642, G=15 region clusters)

| | |
|---|---|
| generated | 2026-08-25 |
| predval commit | golden-freeze commit (regenerated at `cff159d`, the adversarial-ingestion HEAD) |
| GUSTO source | `https://hbiostat.org/data/repo/gusto.rda` (public GUSTO-I teaching release) |

Reproducibility was verified at freeze time: a fresh run reproduced the six byte-identical
artefacts exactly against the prior (the session record) run; `findings.json` differed only in
`provenance.git_commit`, which is why that one field is normalized out of the comparison in
`tests/test_golden_gusto.py`.

To refresh deliberately after an intentional change, see the docstring of
`tests/test_golden_gusto.py`.

These golden artefacts are committed here because they are small and derived from public,
non-sensitive data (GUSTO-I). The fixture *inputs* (`cohort.parquet`, `predictions.parquet`) live
outside git only because they are regenerable derivatives, per `.gitignore`; see the README's
"Reproducing the example" section. Because those inputs are git-ignored, the golden test skips in a
clean checkout that has not built the fixture -- mirroring the PCam golden.
